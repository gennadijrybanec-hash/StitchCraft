# StitchCraft RC8 v136 — быстрый zoom + pan

Контрольная база: v135.

Изменения:
- возвращён быстрый pinch-zoom из поведения v134;
- сохранено перемещение увеличенной схемы одним пальцем из v135;
- при масштабе «По размеру» один палец по-прежнему прокручивает страницу;
- при увеличении один палец перемещает схему внутри окна и не отдаёт жест ScrollView;
- двухпальцевый жест масштабирования снова использует прямой расчёт изменения расстояния между пальцами, затем существующее ускорение zoom;
- compileSdk/targetSdk остаются 36.

Проверить на телефоне:
1. Создать максимальную схему с большим количеством цветов.
2. Быстро увеличить двумя пальцами до размера хорошо видимого крестика.
3. Одним пальцем двигать схему во все стороны.
4. Нажать «По размеру» и убедиться, что смещение сбросилось.
5. Убедиться, что при масштабе «По размеру» страница прокручивается одним пальцем как раньше.
