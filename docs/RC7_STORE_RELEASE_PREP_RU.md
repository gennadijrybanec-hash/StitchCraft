# StitchCraft 1.0 RC7 — Store & Release Prep

Основано на рабочей RC6 FIX1 FastZoom. Ядро генерации схем, сохранение проектов, импорт/экспорт, Aida, прогресс, Undo/Redo и быстрый zoom не переделывались.

## Добавлено
- Кнопка «Материалы» на экране схемы.
- Поиск канвы Aida нужного каунта во внешнем браузере.
- Поиск каждого используемого цвета DMC во внешнем браузере.
- Поисковые запросы не передают в магазин изображение или проект пользователя.
- На экране Pro добавлен блок «О приложении», контакт поддержки и ссылка на опубликованную Privacy Policy.
- versionCode = 108.
- versionName = 1.0.0-rc7-store-prep.
- GitHub Actions переименовывает тестовые артефакты в RC7.

## Что намеренно не добавлено
- Партнёрские/affiliate ID конкретных магазинов — сначала нужны реальные партнёрские аккаунты и их условия.
- Аналитика, реклама и облачная загрузка изображений — декларация Data Safety остаётся простой и соответствует фактическому поведению приложения.

## Следующая проверка
1. GitHub Actions: Debug APK должен собраться.
2. Установить APK поверх предыдущей тестовой версии.
3. Проверить старые функции.
4. Открыть схему → «Материалы» → проверить поиск канвы и 2–3 цветов DMC.
5. Pro → проверить ссылку Privacy Policy.
