# StitchCraft RC8 v138 — компактные элементы управления

Изменения по результатам проверки v137 на Xiaomi Mi 8:

- инструмент `✓ Готово` переименован в более понятный `✓ Отметить`;
- основные инструменты `Отметить / Цвет / Ластик` всегда видимы и не переносятся на две строки;
- `Назад / Вперёд / Меню` собраны в отдельный компактный ряд одинаковой ширины;
- убрана горизонтальная прокрутка панели команд;
- действия `Сохранить / PDF / CSV / PNG` теперь расположены сеткой 2×2 и не уходят за правый край;
- палитра цветов остаётся горизонтально прокручиваемой;
- zoom/pan схемы из v136/v137 не изменялись;
- compileSdk/targetSdk остаются 36.

Версия: versionCode 138, versionName 1.0.0-rc8-compact-controls-sdk36.
