# StitchCraft RC8 Performance v134

Системная оптимизация больших схем и подготовка нового AAB для Google Play.

- `compileSdk = 36` и `targetSdk = 36` подтверждены в исходниках; новый AAB будет собран уже с API 36.
- При импорте больших фотографий больше не декодируется исходник целиком: изображение читается с безопасным `inSampleSize` до рабочего размера, достаточного для сетки до 300 стежков.
- RGB → Lab для клеток схемы вычисляется один раз и повторно используется при подборе палитры, назначении цветов и очистке одиночных стежков.
- Подбор палитры переведён с повторного пересчёта всех ранее выбранных цветов на инкрементальную таблицу лучших расстояний; это особенно ускоряет режим 40–60 цветов.
- Уплотнение палитры больше не создаёт `Set`/`Map` на десятках тысяч клеток.
- Сохранены предыдущие оптимизации v133: bitmap-preview на малом масштабе и отрисовка только видимой части при увеличении.
- Billing, сохранение проектов, экспорт и ограничения Free/Pro не менялись.

Версия: `versionCode 134`, `versionName 1.0.0-rc8-performance-generation-sdk36`.
