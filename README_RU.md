# StitchCraft — восстановленная коммерческая база Android

Это исходный Android-проект на Kotlin + Jetpack Compose.

## Уже реализовано
- выбор изображения из галереи;
- автоматическое масштабирование в сетку крестиков;
- подбор ограниченной палитры ниток из приблизительной DMC-совместимой таблицы;
- назначение уникальных символов;
- интерактивный просмотр схемы с масштабированием;
- легенда цветов и подсчет крестиков;
- полноценное локальное сохранение и повторное открытие схем;
- экспорт PDF постранично, CSV легенды и PNG схемы;
- Free/Pro ограничения;
- Google Play Billing для разовой покупки `stitchcraft_pro_lifetime`;
- восстановление покупки.

## Как открыть
1. Распаковать ZIP на ПК.
2. Открыть папку `StitchCraft_Commercial` в Android Studio.
3. Дождаться Gradle Sync.
4. Запустить на Android 8.0+.

## Перед продажей обязательно
- заменить `applicationId` на уникальный идентификатор вашего бренда;
- подготовить иконку/скриншоты/политику конфиденциальности;
- создать товар `stitchcraft_pro_lifetime` в Google Play Console;
- проверить палитру физических ниток по лицензированному/калиброванному источнику;
- добавить подпись release AAB;
- провести internal/closed testing;
- проверить экспорт на больших схемах и разных языках;
- добавить облачную синхронизацию проектов (опционально).

## Ограничение этой сборки
Среда ChatGPT в этой сессии не содержит полноценного Android SDK/Gradle toolchain, поэтому APK/AAB здесь не собирался. Исходники подготовлены как Android Studio проект. Для публикации всё равно нужен ваш Google Play developer account и ключ подписи.

## Обновление 0.2.0
Генератор схем теперь сравнивает цвета через CIELAB/CIEDE2000 вместо простой RGB-дистанции. Добавлена опция очистки одиночных крестиков, чтобы уменьшать шум на фотографических схемах. Итоговая палитра автоматически сжимается до реально используемых цветов.
