StitchCraft v144 — производительность больших схем (на основе исходников v143)

ИСПРАВЛЕНО В ИСХОДНИКАХ:
- построение миниатюры схемы 300x300 и пересчет статистики выполняются в фоне, а не в потоке интерфейса;
- масштабирование двумя пальцами не перезапускает обработчики касаний при каждом изменении масштаба;
- убрано полное сравнение двух массивов клеток при одном редактировании;
- сохранение, экспорт PDF/CSV/PNG, загрузка и импорт проектов вынесены из главного потока;
- история Undo для схем свыше 40 000 клеток ограничена 8 снимками для экономии памяти;
- versionCode 144, versionName 1.0.2-rc-performance.

ЧТО НЕ МЕНЯЛОСЬ: идентификатор приложения, Billing/Pro, существующие форматы проектов, настройки Firebase (их в этом проекте нет).

ВАЖНО: наличие доступа к PDF/PNG/CSV на телефоне с купленным Pro НЕ доказывает, что эти форматы доступны без Pro. В v143 проверка isPro уже есть перед экспортом. Для проверки Free нужен аккаунт без покупки.

ЗАГРУЗКА В GITHUB (через браузер):
1. Распаковать ЭТОТ архив. Перейти в репозиторий StitchCraft, ветка main (как в присланном GitHub). Add file -> Upload files.
2. Перетащить только папку app из распакованного комплекта. Проверить 2 пути:
   app/build.gradle.kts
   app/src/main/java/com/stitchcraft/app/MainActivity.kt
3. Комментарий коммита: StitchCraft v144: move large pattern work off UI thread
4. Commit changes, перейти Actions -> Build StitchCraft Android. Новые APK/AAB брать из успешного запуска с номером 144.

КОНТРОЛЬНЫЙ ТЕСТ: 300x300, около 47 цветов, дождаться генерации, покрутить/масштабировать, отметить 10 клеток, Undo/Redo, сохранить, экспортировать PNG/PDF/CSV. На телефоне с Pro ограничения Free не проверяются.

Это исходный патч, не готовая APK. Сборку Android в данной среде выполнить нельзя (нет Android SDK/Gradle wrapper). Результат на реальном телефоне ещё не проверен. В рабочий выпуск до испытания НЕ загружать.
