# StitchCraft v1.0 RC3

Предрелизная сборка RC3.

## Исправлено
- Убрано белое системное обрамление вокруг фирменной иконки: launcher-ресурсы теперь полностью непрозрачные.
- Убрана слишком широкая ассоциация файлов `*/*`, из-за которой StitchCraft мог предлагаться Android как приложение для открытия APK и других посторонних файлов.
- Сохранена поддержка открытия `.stitchcraft` по фирменному MIME-типу; импорт из самого приложения остаётся основным и надёжным способом.
- Карточка проекта в портретной ориентации сохраняет действия в одну строку с горизонтальной прокруткой.
- GitHub Actions публикует артефакт с правильным названием RC3.

## Сохранено без изменений
- Фото → схема, DMC, Aida, физический размер.
- Масштабирование и перемещение схемы.
- Постоянные отметки вышитых крестиков и счётчик прогресса.
- Проекты, переименование, удаление, импорт/экспорт `.stitchcraft`.
- PDF, PNG и CSV.
- Экран Pro и Google Play Billing-заготовка.
