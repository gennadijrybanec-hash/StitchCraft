# StitchCraft v147 — коммерческий кандидат для Google Play

Основа: полный исходник v146. Контрольный исходник v146 не изменён.

* Сохранены настоящие ограничения Free: ширина до 80, 24 цвета; Pro: ширина до 300, 60 цветов.
* Pro выдаётся только по подтверждённой покупке Google Play Billing; тестовых переключателей Pro в основной сборке нет.
* Кнопки «Открыть», «Переименовать», «Экспорт», «Удалить» в карточке проекта располагаются в двух строках и доступны на узких экранах без боковой прокрутки.
* Исправлена нумерация и названия результатов GitHub Actions для версии 147; убрана лишняя интерактивная проверка keystore, которая могла блокировать выпуск.

## Перед публикацией

1. Загрузить исходник в репозиторий, запустить workflow Build StitchCraft Android и проверить, что подписанный AAB собирается без ошибок. В этом окружении Android SDK/Gradle отсутствуют, сборка и проверка на телефоне не выполнялись.
2. Убедиться, что секреты STITCHCRAFT_UPLOAD_KEYSTORE_B64, STITCHCRAFT_KEYSTORE_PASSWORD, STITCHCRAFT_KEY_ALIAS, STITCHCRAFT_KEY_PASSWORD соответствуют действующему ключу загрузки этого приложения.
3. В Play Console активировать разовый товар stitchcraft_pro_lifetime, цену и доступность. Проверить покупку/восстановление с установленной из Google Play сборкой; обычный debug APK не доказывает корректность покупок.
4. Повторить проверку интерфейса на Mi 8 и функции Free/Pro, выполнить обязательные шаги Play Console. Только после этих проверок продвигать сборку в production.
