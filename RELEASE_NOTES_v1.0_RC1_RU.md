# StitchCraft v1.0 RC1

Предрелизная сборка на базе проверенной v0.15.2.

## Что сохранено
- Фото → схема.
- Палитра ниток и символы.
- Aida 14/16/18 и физический размер.
- Масштабирование до 2000%, панорамирование и сетка 10×10.
- Постоянные отметки вышитых крестиков и корректный счётчик прогресса.
- Сохранение, открытие, переименование и удаление проектов.
- Экспорт/импорт `.stitchcraft`.
- PDF, PNG и CSV.
- Фокус по выбранному цвету.
- Undo/Redo.

## Исправления и усиление RC1
- Версия приложения: `1.0.0-rc1`, versionCode 100.
- Pro-лимит цветов приведён к реально доступной проверенной палитре: до 60 цветов. Это устраняет скрытый сбой генерации при выборе 100–200 цветов.
- Генератор дополнительно страхует число цветов от выхода за размер палитры/набора символов.
- Большие исходные фотографии декодируются с уменьшением, чтобы снизить риск нехватки памяти.
- PNG для больших Pro-схем автоматически уменьшает размер клетки, чтобы не создавать чрезмерно большой Bitmap.
- PDF теперь содержит полную легенду всех цветов на дополнительных страницах; цвета больше не обрезаются первыми 24.
- CSV корректно экранирует кавычки в названиях ниток.
- Импорт проекта строже проверяет размеры, палитру, индексы клеток и массивы прогресса.
- Открытие `.stitchcraft` из Android обработано и для уже запущенного приложения.
- Добавлена базовая иконка приложения.
- BillingClient корректно закрывает соединение при уничтожении Compose-экрана.
- GitHub Actions теперь не только собирает APK, но и запускает unit-тесты и Android Lint.
- Добавлены unit-тесты на накопление/снятие отметок и подсчёт прогресса.

## Перед финальной v1.0
1. Пройти единый RC-чек-лист на смартфоне.
2. Настроить товар `stitchcraft_pro_lifetime` в Google Play Console и проверить покупку во внутреннем тесте.
3. Создать приватный release/upload key. Тестовый ключ из репозитория нельзя использовать для публикации.
4. Подтвердить финальную политику конфиденциальности и Data Safety.
5. Подготовить магазинную иконку 512×512, Feature Graphic и скриншоты.
6. Для расширения палитры выше 60 цветов нужен проверенный источник/набор оттенков; RC1 намеренно не обещает 200 цветов, которых текущая палитра фактически не содержит.
