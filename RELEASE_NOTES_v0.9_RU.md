# StitchCraft v0.9.0 — тестовая сборка

## Что изменено

- максимальный масштаб схемы увеличен до 20×;
- кнопки масштаба работают крупнее, рядом показывается текущий процент;
- перемещение увеличенной схемы ограничено так, чтобы её было сложнее полностью «потерять» за пределами экрана;
- добавлена более заметная направляющая сетка 10×10;
- сохранена контрастная отрисовка символов на светлых и тёмных цветах;
- добавлена постоянная тестовая подпись debug APK для GitHub Actions;
- версия приложения: 0.9.0 (versionCode 9).

## Важно о подписи

Файл `app/stitchcraft-test-debug.keystore` предназначен **только для тестовых debug-сборок**. Он специально хранится в тестовом проекте, чтобы APK, собранные разными GitHub Actions runners, могли обновлять друг друга.

Для Google Play / коммерческого релиза этот ключ использовать нельзя. Перед релизом будет создан отдельный приватный release/upload key, который не должен попадать в репозиторий.

Поскольку v0.8 была собрана старой случайной debug-подписью, при переходе с v0.8 на v0.9 потребуется ещё один раз удалить приложение. Начиная с v0.9 последующие debug-версии, использующие этот ключ, смогут устанавливаться поверх неё.
