# StitchCraft v0.7 — сборка APK только со смартфона

Это рекомендованный путь для владельца Android-смартфона без компьютера.
Сам телефон не компилирует приложение: сборку выполняет GitHub Actions на Linux-сервере, а телефон используется для загрузки проекта и скачивания APK.

## Что понадобится
- аккаунт GitHub;
- браузер на смартфоне;
- архив StitchCraft_Commercial_Source_v0.7.zip.

## Пошагово
1. В браузере открыть github.com и войти в аккаунт.
2. Создать новый приватный репозиторий с именем `StitchCraft`.
3. Не добавлять README/.gitignore/license при создании, чтобы репозиторий был пустым.
4. Распаковать ZIP проекта на телефоне.
5. Загрузить содержимое папки `StitchCraft_Commercial` в корень репозитория. В корне GitHub должны быть видны `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`.
6. Открыть вкладку Actions.
7. Выбрать workflow `Build StitchCraft APK`.
8. Нажать `Run workflow` → `Run workflow`.
9. После завершения открыть выполненный запуск.
10. Внизу страницы в разделе Artifacts скачать `StitchCraft-debug-apk`.
11. Распаковать скачанный ZIP — внутри будет `app-debug.apk`.
12. Разрешить браузеру/файловому менеджеру установку неизвестных приложений, если Android попросит.
13. Установить `app-debug.apk`.

## Если сборка красная
Открыть неуспешный workflow → шаг `Build debug APK` → скопировать текст ошибки и прислать его в ChatGPT. По этой ошибке проект можно исправить в следующей версии.

## Техническая база
Проект использует Android Gradle Plugin 8.7.3, для которого Gradle 8.9 и JDK 17 соответствуют официальным требованиям совместимости.
